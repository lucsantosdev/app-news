# news-app
> Este proyecto es un sitio web de noticias o aplicación web elegante y adaptable, creado mediante el consumo de API.

🌍 **Idiomas:** [Português](README.pt-BR.md) | [English](../README.md)

![Project Presentation](/app/public/presentation-app.gif)


## 🚀 Descripción del Proyecto  
Esta es una aplicación web de noticias que presenta artículos y noticias de EE. UU. en varias categorías, con actualizaciones y enlaces a las fuentes de noticias correspondientes. Este proyecto se desarrolló utilizando React JS, Bootstrap y el consumo de API por [NewsAPI](https://newsapi.org/). 

## ✨ Funcionalidades
- **Variedad de noticias:** noticias clasificadas por categorías de interés principales.
- **Diseño Elegante:** interfaz de usuario e interacción atractivas, desarrolladas con React JS y Bootstrap.
- **Consumo de API:** localiza artículos y titulares de última hora provenientes de fuentes de noticias y blogs de toda la web mediante una API JSON.
- **Hyperlinks:** cada artículo está enlazado a la página web de su fuente original.
- **Diseño Responsivo:** interfaz que funciona a la perfección en diversos dispositivos, mejorando la accesibilidad.

## 📦 Instalación 
1. Clona el repositorio:  
   ```bash
   git clone https://github.com/lucsantosdev/news-app.git
2. Naviga hasta el directorio de la aplicación:  
   ```bash
   cd news-app/app
3. Instalar dependencias:  
   ```bash
   npm install
4. Ejecuta el proyecto:  
   ```bash
   npm run dev
5. Abre http://localhost:5173 para verlo en su navegador.

## 📖 Cómo utilizar la clave de NewsAPI
1. Accede al [sito web de NewsAPI](https://newsapi.org/) y regístrate para obtener su clave de NewsAPI.
2. Crea un archivo '.env' y pega su clave de API (consulta el archivo '.env-example').
3. A continuación, podrás utilizar la clave de API en el archivo 'components/NewsBoard.jsx'.
4. Consulta la documentación de NewsAPI ([disponible aquí](https://newsapi.org/docs)) para conocer otras formas de utilizarla.
