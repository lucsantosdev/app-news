# news-app
> Este projeto é um website/aplicação web de notícias elegante e responsivo feito com consumo de API externa.

🌍 **Idiomas:** [English](../README.md) | [Español](README.es.md)

![Project Presentation](/app/public/presentation-app.gif)


## 🚀 Descrição do Projeto  
Este é uma aplicação de notícias que apresente artigos e notícias (de fontes estadunidenses) em várias categorias com atualizações e links para sua respectiva fonte de notícias. Este porjeto foi construído usando React JS, Bootstrap e consumo de API da [NewsAPI](https://newsapi.org/). 

## ✨ Funcionalidades 
- **Variedade de Notícias:** notícias distribuídas por principais categorias de interesse.
- **Design Elegante:** linda interface de usuário e interação usando React JS e Bootstrap.
- **Consumo de API:** localiza artigos e manchetes de notícias de última hora provenientes de fontes de notícias e blogs de toda a web, utilizando uma API JSON.
- **Hyperlinks:** cada artigo de notícia está vinculado à página da sua respectiva fonte de notícias.
- **Design Responsivo:** interface de usuário que funciona de forma integrada entre diferentes dispositivos, melhorando a acessibilidade.

## 📦 Instalação 
1. Clone o repositório:  
   ```bash
   git clone https://github.com/lucsantosdev/news-app.git
2. Navegue até o diretório da aplicação (news-app/app):  
   ```bash
   cd news-app/app
3. Instale as dependências:  
   ```bash
   npm install
4. Execute o projeto:  
   ```bash
   npm run dev
5. Abra http://localhost:5173 para visualizar no seu navegador.

## 📖 Como usar a NewsAPI Key
1. Acesse o [site NewsAPI](https://newsapi.org/) e registre-se para obter sua chave de API (NewsAPI).
2. Crie um arquivo '.env' e cole sua chave de API (confira o arquivo '.env-example').
3. Depois disso, você pode usar sua chave de API no arquivo 'components/NewsBoard.jsx'.
4. Confira a documentação da NewsAPI ([disponível aqui](https://newsapi.org/docs)) para mais formas de usá-la.
