## 🚀 Project Description  
This is a news web application that presents US articles and news in various categories with updates and links to the respective news sources. This project was build using React JS, Bootstrap and API consumption by [NewsAPI](https://newsapi.org/). 

## ✨ Functionalities  
- **Variety of News:** news distributed by main categories of interest.
- **Elegant Design:** beautiful user interface and interaction by using React JS and Bootstrap.
- **API Consumption:** it locates articles and breaking news headlines from news sources and blogs across the web with JSON API.
- **Hyperlinks:** each news article is linked to their respective news source webpage.
- **Responsive Design:** UI that works seamlessly across devices, enhancing accessibility.

## 📦 Installation  
1. Clone the repository:  
   ```bash
   git clone https://github.com/lucsantosdev/news-app.git
2. Navigate to the app directory:  
   ```bash
   cd news-app/app
3. Install dependencies:  
   ```bash
   npm install
4. Run the project:  
   ```bash
   npm run dev
5. Open http://localhost:5173 to view it in your browser

## 📖 How to Use NewsAPI Key
1. Access [NewsAPI website](https://newsapi.org/) and register yourself for getting your NewsAPI key.
2. Create a file '.env' and paste your API key (check the file '.env-example').
3. After that, you can use the API key in the file 'components/NewsBoard.jsx'.
4. Check out the documentation of NewsAPI ([avaliable here](https://newsapi.org/docs)) for more ways of using it.
